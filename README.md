**Solara Heat** — an original open-world crime game that plays in a desktop browser from static files. No build step, no network, no assets: every street, siren and screenshot is generated by the code in `game/`.

You are Rio Vega, a runner in the sun-soaked coastal city of Solara Bay, working for fixer Mama Sol. Her chain of five jobs — a package run, a timed night fare, losing a police tail, ram-settling a rival courier, and one hot duffel out of Banco Solara — is the story. Every crime feeds a five-star wanted system: patrol cars hunt you, box you in and fill the bust meter. Finish all five jobs to take the city; get busted or run down and the run ends.

In the world: a 30-block city grid with eight named places (Sol's Diner, Hotel Palmera, Banco Solara, Club Neon Palms, Tito's Auto, Mercado Sol, Marina Del Sol, Solara Airstrip), parks and parking lots; lane-following traffic that brakes and turns; pedestrians who stroll the pavements and scatter from fast cars; cars to steal and drive with arcade physics and a handbrake; cash bags on street corners; a HUD with cash, wanted stars, the current objective and its timer, an off-screen direction arrow, a live minimap with police blips, and speed/health gauges; synthesized engine, siren and jingle sounds (WebAudio, no audio files); and a best-take save in localStorage.

**Controls** — WASD / arrow keys move and drive · **E** steal or leave a car · **SPACE** handbrake · **M** mute · **ENTER** start / run it again.

The source is split one job per file under `game/src/`: `city.js` lays out Solara Bay, `entities.js` moves the player, traffic, the rival and pedestrians, `wanted.js` runs the heat and the bust meter, `jobs.js` is Mama Sol's job chain, `game.js` is the simulation step that wires them together, `render.js` and `hud.js` draw it, `audio.js` synthesizes the sound, and `shots.js` stages the screenshot scenes inside the real game. The simulation modules never touch the DOM, so the same code that plays in the browser also runs in headless tests (determinism, a completable campaign, police response and arrest).

The four screenshots in `screenshots/` are real frames of the game running in Chrome, staged by `game/src/shots.js`: the title over the living city, the timed Night Fare at speed, a three-star duffel chase with the bust meter filling, and Rio on foot at the first job's marker outside Sol's Diner.

## Run it

```sh
node serve.ts
```

then open http://localhost:8080 in desktop Chrome. To hand the entry in the way the grader does: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts` — `main.ts` copies `game/` and `screenshots/` to the output directory and writes its `dossier.json` with the vendored `vendor/makefun-game.ts`.
